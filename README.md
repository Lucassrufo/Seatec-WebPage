# 🚀 Seatec Soluções Tecnológicas — Website Institucional

Site institucional moderno da **Seatec Soluções Tecnológicas**, desenvolvido com foco em performance, design premium e conversão.

🔗 Apresenta os sistemas:

- **VoePDV (Windows)**
- **PDV Legal (Android)**

---

## ✨ Visão Geral

Este projeto é um website completo com múltiplas páginas, criado para destacar soluções de automação comercial com uma experiência visual moderna, fluida e profissional.

O foco é:

- Alta conversão
- UX premium
- Performance
- Escalabilidade
